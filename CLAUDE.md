# Global AI Agent Rules for this Repository

## 1. Language Constraints

- **CRITICAL:** ALWAYS write code, variables, comments, documentation, and commit messages entirely in ENGLISH.
- Never use German or any other language, even if the user prompts in German.

## 2. Tech Stack & File Formats

- **CRITICAL:** ALWAYS use TypeScript. Never use JavaScript.
- Never generate `.js` or `.jsx` files. Only use `.ts` and `.tsx`.
- Framework: React (via Vite) with Tailwind CSS.

## 3. Execution

- Run tests before implementing complex logic.
- Keep components small, modular, and strictly typed.
